slide-01: Cover. Give an AI a computer. Take it back at a time you choose. RESENTMENT OS 2.0.0, an AI operating system on its own kernel and your own key.
slide-02: The problem: most AI operating systems are a chat window with file access. Allow means forever. RESENTMENT OS is built on a kernel whose ideas the desktop repeats.
slide-03: Idea one: authority expires. Every permission an agent holds is a lease with a deadline, shown as a draining ring. In the kernel every capability carries a seal with a time window.
slide-04: Idea two: the system is a hash. One SHA-256 root over every file and setting, no timestamps, no keys. Snapshot, diff, attest. The kernel has one root for the whole machine.
slide-05: Idea three: agents are processes. A process table with id, state, tokens against budget, and a kill button for each agent. In the kernel, inference is a scheduling class.
slide-06: Idea four: nothing is forgotten. A ledger where every tool call is an entry, every file change names its cause, and undo is a new entry. The kernel records events in causal order.
slide-07: Any provider, your key, no middleman. Chips for Anthropic, OpenAI, Gemini, Groq, Mistral, xAI, DeepSeek, OpenRouter, Together, Ollama, LM Studio and any URL. No server, no telemetry.
slide-08: The kernel is real: a boot transcript showing self-tests passing and the OS's program refused, granted, then run. From scratch for x86_64, ARM64 and RISC-V, driven by the desktop over a serial bridge.
slide-09: Status, honestly. Working: the desktop, the providers, leases and ledger, the kernel booting through the bridge in CI. Not yet: the desktop running inside the kernel.
